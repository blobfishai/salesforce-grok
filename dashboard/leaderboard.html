Methodology

  • World: blobfish deep world sbx_36847f702cef4cb4 (49 tables / 171 tools / wave-5 hardening: conflicting SOP versions, conditional rules, entity collisions). Sessions are copy-on-write SQLite; every trial runs in a fresh session.
  • Task set: 15 wave-5 frontier tasks + 2 procedure-following probes (task_008, task_012 — tasks with a mandated required_workflow_path). Turn budget is reference-relative: max(24, 3×reference-walk + 6).
  • Scoring: the world's own VCode verifiers — deterministic Python verify(initial_state, final_state, trace) asserting state deltas, read-before-write, no off-task/undeclared writes, append-only audit logs, and (where mandated) workflow path. No LLM judge anywhere in scoring.
  • Arena: 6 CRMArena-style tasks (case routing, top issue, handle time, BANT lead qualification, policy violation, entity disambiguation) at level-2 hardening (near-ties, superseded policies, decoys), exact/fuzzy/set match, flat 16-turn cap.
  • Models called through each provider's native OpenAI-compatible endpoint, identical prompts and tool schemas (dotted MCP names mangled to API-safe form uniformly for all providers). Pricing from provider price pages, verified 2026-08-09.
