# Research questions — sales world (question-led, not one-shot)

Answers accumulate in research/answers/<slug>.md with links. A question is open
until its answer file cites sources.

## Domain
1. What is the exact business (segment, deal size, motion: inbound/outbound/PLG)?
2. What is the business value chain — lead → close → renew — and where does money leak?
3. Who are the stakeholders (SDR, AE, AM/CSM, RevOps, Deal Desk, Finance, Marketing) and what does each DO daily?
4. What counts as "done" for each stakeholder's tasks (definition of done per workflow)?

## Tools
5. Which tools does each stakeholder actually touch, per workflow? (map stakeholder × workflow × tool)
6. For each tool: what are the real API/MCP verbs? (research/tools/<product>.md — official MCP docs, OpenAPI, GitHub usage workflows)
7. Where does the SAME data live twice (CRM vs spreadsheet vs billing) and how does it drift?

## Tasks
8. Which tasks appear in evals/arenas (CRMArena/-Pro, tau-bench-class, AI-SDR repos) — and which daily tasks appear in NO eval yet?
9. What are the input documents per task (call transcript, order form, thread, sheet)?
10. What are the chaos scenarios practitioners describe (sync lag, dup leads, partial migrations, wrong owner)?

## Verification
11. For each task: what state change proves completion? What collateral must NOT change?
12. Which tasks are answer-tasks (analytics) vs state-tasks (mutations) vs communication-tasks (needs transcript-level assertions)?
