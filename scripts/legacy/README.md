# Legacy reporting scripts

These built dashboard and proof pages from the pre-consolidation worlds
(`world/arena`, `world/blobfish`, `world/blobfish-wave2..5`), all of which were
removed when the project consolidated onto a single world. They are kept for
provenance — the pages they generated are cited in `docs/` — but they will not
run against the current tree.

The world they targeted is recoverable from git history if a page needs
regenerating.
